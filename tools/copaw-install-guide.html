常见问题 FAQ

Q: 安装过程中遇到报错怎么办？

A: 大部分问题都是环境变量未生效导致的，关闭 cmd 窗口重新打开即可解决，有时候重启一下就能解决。

Q: API 密钥在哪里购买？

A: 推荐阿里云的Coding Plan 首页7.9 包月制 不会产生额外费用。

Q: 可以在 Mac 或 Linux 上安装吗？

A: 本文主要针对 Windows 系统，Mac/Linux安装过于简单 我就没写 可以在官方教程查看。

Mac/Linux 安装只需要一句话：

Q: OpenClaw 和 CoPaw 是什么关系？

A: CoPaw 是阿里推出的优化版本 OpenClaw 功能一致 占用资源更少。

Q: 安装完成后，如何启动 CoPaw？

A: 安装完成后，在 cmd 中输入 copaw app 即可启动 CoPaw。 启动后不要关闭 cmd 窗口，否则 CoPaw 会停止运行。

Q: 最低的系统要求是什么？

A: CoPaw 最低要求 Windows 10 或以上版本，建议使用 Windows 11。如果版本过低会卡在python环境安装那步。

总结

安装完成后，你就可以：

  • 通过 Web 界面 (http://127.0.0.1:8088) 与 AI 助手交互
  • 通过飞书远程下达任务
  • 导入各种技能扩展功能
  • 配置不同的 AI 模型（支持阿里云 Qwen3.5 Plus 等）

如果在安装过程中遇到问题，可以检查以下几点：

  1. 确保网络连接正常
  2. 确认已正确添加环境变量
  3. 检查 API 密钥是否有效
  4. 查看官方文档或联系支持
