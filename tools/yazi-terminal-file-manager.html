Yazi 是基于 Rust 的极速终端文件管理器，支持图片预览、Vim 键位和 Lua 插件系统。本文涵盖 macOS 安装、13 个依赖工具配置、10 个必备插件安装以及完整快捷键使用指南。

依赖工具安装

Yazi 依赖一系列 CLI 工具来实现文件预览、搜索等功能：

工具 用途
ffmpeg 视频/音频缩略图生成
p7zip (7z) 7z 压缩/解压
poppler (pdftoppm) PDF 预览
fd 快速文件查找（替代 find）
fzf 模糊搜索
zoxide 智能 cd（跳转常用目录）
resvg SVG 渲染
imagemagick (convert) 图片处理/转换
glow Markdown 终端预览
mediainfo 媒体文件元数据读取
ouch 压缩包内容预览/压缩/解压
jq JSON 预览（macOS 自带）
rg (ripgrep) 内容搜索

使用指南

启动

基础导航

按键 功能
h / ← 返回上级目录
l / → 进入目录 / 打开文件
j / ↓ 向下移动
k / ↑ 向上移动
Enter 智能打开（smart-enter 插件）
f 跳转到文件名首字符（jump-to-char 插件）
~ 跳转到家目录
g + c 跳转到 ~/.config
g + d 跳转到 ~/Downloads
z 用 zoxide 跳转常用目录
Z 用 fzf 跳转目录

文件操作

按键 功能
y 复制（yank）
x 剪切（cut）
p 粘贴（smart-paste：粘贴到悬停目录）
P 粘贴到当前目录（强制）
d 删除（移到回收站）
D 永久删除
a 新建文件/目录（末尾加 / 表示目录）
r 重命名
. 切换隐藏文件显示

选择

按键 功能
Space 切换选中当前文件
v 反选
V 进入/退出可视模式（批量选择）
Ctrl+a 全选
Ctrl+r 取消全选

预览与搜索

按键 功能
Tab 查看文件详细信息（spotter）
/ 过滤/搜索当前目录文件
? 查看帮助
Ctrl+/ 查看快捷键列表

标签页

按键 功能
t 新建标签页
1-9 切换到第 N 个标签页
[ / ] 切换到上/下一个标签页
Ctrl+c 关闭标签页

自定义命令打开

按键 功能
o 选择程序打开文件（open-with-cmd 插件）
O 同上（阻塞模式）

退出

按键 功能
q 退出
Q 退出并将当前路径输出到终端（配合 y 函数使用）
Ctrl+c 强制退出

常见问题

TOML parse error: at least one of url or mime must be specified

新版 Yazi 预览器配置格式变更，name 键已废弃。用 url 匹配文件路径 glob，用 mime 匹配 MIME 类型。

ouch 插件 Lua error

确保安装了 ouch CLI 工具：brew install ouch
